# Privacy and security

A Discord archive can contain private messages, names, avatars, files, and sensitive material. Keep it in an encrypted or access-controlled location, do not publish it accidentally, and share it only with people authorized to receive the server’s content.

Use the exporter only for a server where the archive is authorized. The bot token is equivalent to a password: keep it out of source control, logs, screenshots, and the output folder. Revoke the token in Discord immediately if it is exposed.

The export is a point-in-time copy. It cannot include content deleted before it ran, and it does not watch future edits or deletions. Before distributing an archive, review Discord’s developer terms, the server’s rules, and any applicable privacy or retention obligations.
